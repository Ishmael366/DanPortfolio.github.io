# Creek Environment

Independent browser adaptation of the project concept, built with JavaScript and WebGL. This is not a packaged Unreal Engine build.

## Play

https://ishmael366.github.io/DanPortfolio.github.io/unreal-demos/unreal-09585f9fb6/

## Included mechanics

- Creek and bridges
- Free movement
- Collectible route

## Files

- `config.json`: project-specific setting, objective and controls.
- `index.html`: playable page.
- `../engine.js`: shared browser implementation.
- `../vendor/THREE-LICENSE.txt`: required renderer license.
