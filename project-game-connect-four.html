01

Experience

Drop pieces into a vertical grid and try to connect four of your own. A move changes both the visible pattern and the available landing positions in that column.

02

Description

A piece falls to the lowest available position in its chosen column. That stacking rule makes the shape of the existing board as important as the location where the player would like to form a line.

Play involves building horizontal, vertical, or diagonal threats and recognizing which columns would give the opposing side a winning move. The result of each turn remains visible on the board.

03

Detailed features

Column-based piece placement

The whole board provides the state for a strategic decision. Each placement or move changes both the player’s opportunities and the threats that need to be prevented.

Turn-based strategy

Turn-based interaction separates choosing an action from resolving it. That structure gives the player time to compare options and understand the resulting change in game state.
