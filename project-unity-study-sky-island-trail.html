Experience

Cross a route of twelve floating islands using third-person movement and carefully judged jumps.

02

Description

The islands divide the route into separate landing areas. Each gap asks the player to compare the distance ahead with the character’s movement and jump.

A safe landing provides the next position from which to continue the route. The focus is traversal through the twelve-island layout, not an unverified set of additional levels or combat encounters.

03

Detailed features

Twelve-island route

This part of the project contributes to the core interaction described above. Its role is presented through the project’s available interface, source, and visual preview.

Third-person movement

Movement and viewpoint work together to make the space readable. The player uses the controls to choose a route, judge distance, and position the character for the next interaction.

Gap jumping

Traversal combines horizontal movement with jump timing and landing position. Platform spacing turns the level layout into a sequence of movement decisions.
