Sky Island Trail

Overview

A third-person platforming game set across twelve islands. The player moves between separated pieces of terrain, using jumps and position to continue along the route.

Gaps turn the island layout into the main traversal challenge. Each landing provides a new position from which to judge the next jump, while the third-person camera keeps the character and the space ahead visible. The overview presents the floating-island route and the movement system together.

What it includes

  • Twelve-island route
  • Third-person movement
  • Gap jumping
