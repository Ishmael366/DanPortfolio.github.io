Spotify Music Interface

Overview

A music dashboard with searchable collections, saved tracks and a working sample-audio player.

An independent tutorial-derived interface study adapted for browser-only presentation. Saved collections stay in this browser. Playback uses short sample media; account services and full commercial streaming are outside this demo.

Tutorial sources and adaptations are documented in SOURCE.md alongside the code.
