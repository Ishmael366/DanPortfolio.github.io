Fruit Slice

Overview

A browser adaptation of the Unity fruit-slicing mechanics with drag gestures, sliced-fruit effects and scoring.

Hold and drag the mouse or your finger to slice fruit. Five misses ends the round.

This is a JavaScript core-mechanics adaptation of the saved Unity tutorial source. Rendering, levels, balance and interface differ from the original engine build. The source archive includes the browser implementation, source mapping and selected original controller scripts with notices.

Browser startup, rendering and representative controls have been checked. Full equivalence to the original tutorial project is not claimed.
