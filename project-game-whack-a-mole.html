01

Experience

React to targets as they appear and select them before the opportunity disappears. The game uses a compact play field so attention stays on the next active target.

02

Description

The board changes its active target repeatedly. The player must identify the new location, respond, and return attention to the whole field for the next appearance.

The short interaction loop makes response time the main challenge. Each hit or missed appearance provides another step in the score or the flow of the round.

03

Detailed features

Appearing targets

Targets provide a readable goal for interaction. Their position establishes the aiming challenge, while their response shows whether the action succeeded.

Reaction-based input

The play field changes quickly, so the player must identify an active target and respond in time. A successful interaction produces immediate visual feedback.

Repeated action loop

This part of the project contributes to the core interaction described above. Its role is presented through the project’s available interface, source, and visual preview.
