Whack A Mole

Overview

React to targets as they appear and select them before the opportunity disappears. The game uses a compact play field so attention stays on the next active target.

The interaction is intentionally immediate: observe the board, recognize an appearance, and respond. Repeated appearances create the rhythm of play and make reaction speed the central challenge. The overview shows the game’s target presentation and introduces the timing-based action.

What it includes

  • Appearing targets
  • Reaction-based input
  • Repeated action loop
