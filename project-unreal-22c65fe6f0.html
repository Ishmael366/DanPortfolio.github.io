Experience

A single-player, endless 3D runner set in an obstacle-filled tunnel, where increasing speed makes collecting coins progressively harder.

02

Description

The goal is to beat a personal record by gathering as many coins as possible while surviving the tunnel. New sections keep appearing ahead of the character, and sections that have already been passed are removed. This creates a continuing route rather than a finite set of hand-placed levels.

The pace rises as the run continues. Obstacles and enemies compete with the opportunity to collect more coins. Temporary bonuses can allow movement through walls or double the value of collected coins, adding short periods in which the best route changes. Movement is documented through WASD or the arrow keys.

03

Detailed features

Procedural tunnel sections

Platforms are generated continuously and removed after the player passes them. The route can continue indefinitely while the active scene remains focused on the area around the character.

Increasing speed and coin collection

Forward speed rises as the run progresses. The same collection action becomes more demanding because the player has less time to react to obstacles and choose a route.

Temporary bonuses

The documented bonuses include passing through walls and receiving double coins for a limited time. These effects alter the value and danger of a route during the run.

04

Build summary

The source describes an Unreal Engine 4, single-player 3D platform runner. Its central systems are procedural section creation and removal, increasing speed, coin scoring, obstacles and enemies, and timed bonuses.
