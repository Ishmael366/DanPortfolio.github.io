Experience

A first-person combat project focused on a visible character body, health and armor feedback, animation transitions, and an equipped AK-style weapon.

02

Description

The project develops a true first-person viewpoint from a third-person character setup. Character movement and direction feed an animation graph, while the camera places the player inside that character’s perspective.

Health and armor are shown through progress bars. Damage-trigger areas affect those values, armor can regenerate, and a blood-splash overlay communicates injury. The documented weapon work adds an AK-47 model, materials, a starting equipped state, and the beginning of its firing interaction.

03

Detailed features

True first-person character setup

The source describes changing a third-person setup into a first-person view while retaining character animation. Movement direction and speed select transitions in the animation Blueprint.

Health, armor and damage feedback

HUD bars expose health and armor. Regenerating armor, damage triggers, and a blood-splash overlay connect changes in gameplay state to immediate visual feedback.

Equipped weapon and firing work

The weapon model and materials are imported and the character begins with the weapon equipped. The documentation then proceeds into the firing implementation.

04

Build summary

This Unreal source project combines a first-person camera, character and weapon assets, animation Blueprint logic, health and armor UI, damage triggers, regenerating armor, and a damage overlay. The source documentation records the implementation in stages rather than establishing a finished campaign.
