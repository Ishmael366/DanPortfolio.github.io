Description

The route is built from the relationship between the character’s jump and the platforms above it. Horizontal adjustment determines whether the next arc becomes a safe landing or a missed opportunity.

The scene emphasizes upward progress and the need to plan beyond the platform currently underneath the character. Each landing establishes the starting position for the next choice.
