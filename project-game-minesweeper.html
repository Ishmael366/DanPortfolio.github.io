Experience

Reveal cells on a hidden board while using numerical clues to avoid mines. Safe openings provide information about nearby danger and guide the next choice.

02

Description

A revealed number describes the mines around that cell. Each safe opening adds information, allowing the player to identify more promising moves or mark cells that appear dangerous.

The central interaction is deduction rather than rapid movement. A move is valuable both for the space it opens and for the information it provides about the remaining board.

03

Detailed features

Hidden-cell board

Part of the board is concealed, so each reveal adds information. The player uses earlier results to make a more informed choice on the next move.

Numerical clues
