Experience

An arena networking project organized around starting a host session and joining it from another client.

02

Description

The native source includes a host-and-join workflow implemented with UDP sockets. This gives the arena a networking architecture in addition to the local character and scene presentation.

Native UDP connectivity is not supplied by an ordinary browser runtime. The browser presentation and the networking source are therefore distinct parts of the entry; the overview does not claim verified browser-to-browser multiplayer.
