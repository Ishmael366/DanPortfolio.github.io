Candy Crush

Overview

Match colored candies by arranging compatible pieces on a grid. Successful matches change the board and create new opportunities for the next move.

The board is both the play space and the main source of feedback: colors and positions show which combinations are available. The player looks for useful swaps and follows the resulting changes to continue scoring. This overview presents the matching mechanic and the appearance of this particular version.

What it includes

  • Candy grid
  • Matching combinations
  • Board updates and score
