Experience

Choose rock, paper, or scissors and compare the selection with the computer’s move. Each round resolves according to the familiar three-way set of winning relationships.

02

Description

Each choice wins against one option and loses against another. The player selects a move, the computer provides its response, and the interface communicates which relationship determined the result.

The familiar three-way rule makes the game easy to understand. Its build is centered on move selection, outcome evaluation, and feedback for another round.

Round results

The interface communicates the result of an action or the progress toward an objective. That feedback makes the current state and the next goal easier to understand.
