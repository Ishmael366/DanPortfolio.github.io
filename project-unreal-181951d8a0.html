Experience

A 2.5D side-scrolling character framework with a constrained movement plane, an adjustable camera, and configurable movement properties.

02

Description

The source modifies an Unreal Engine third-person template into a side-view setup. Movement is constrained to the intended plane, so a three-dimensional character can be used in a platform game that is read from the side.

Enhanced Input handles controls. Walk speed, gravity, and camera offset can be adjusted to suit a level. A camera-height lock supports flatter routes, while the documented alternative allows the camera to follow vertical movement; a spline is suggested for more precise camera positioning.

03

Detailed features

Constrained 2.5D movement

The framework limits movement to a side-scrolling plane. This changes how the character navigates the same underlying three-dimensional world.

Enhanced Input and movement tuning

The project uses Enhanced Input and exposes movement values such as speed and gravity. These are the foundations for adapting the controller to different platform layouts.

Camera height and framing

A height-lock option supports levels with little vertical travel. Turning it off lets the camera follow the character vertically, and camera offset values control the framing.

04

Build summary

The project is a Blueprint modification of an Unreal Engine 5 third-person template, with Enhanced Input and camera-manager configuration. It is a character-and-camera foundation; the saved documentation does not establish a finished multi-level game.
