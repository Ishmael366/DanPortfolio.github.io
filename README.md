# Daniel Nguyen Portfolio

Static portfolio with Labyrinth, 31 project overviews, résumé, and twelve skill areas.

## Publish
GitHub Pages: deploy main branch, repository root. All site files are served from the root.

## Preview
Run `python3 -m http.server 4193` from this directory.

## Source
The published HTML, CSS, JavaScript and assets are in the root. Catalog JSON and the original generator are retained for editing; the generator expects a dist directory, so generate there and copy the output to the root when rebuilding.
