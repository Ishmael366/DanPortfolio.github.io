# Daniel Nguyen Portfolio

Static portfolio with Labyrinth, 34 project overviews, résumé, and twelve skill areas.

## Graphics presentations

Open Entertainment & Videos for the Netflix, Disney+ and Spotify interface demos. The three `*-demo.html` files are self-contained application bundles with adjacent local media, ready for GitHub Pages. Browser saved lists and sample playback work without accounts.

Full editable tutorial projects, provenance, dependency lockfiles and the static build adapter are saved in `Graphics_Batch_01_Source.zip`. Extract it to work on the source. Install dependencies in each project as described in its README. Private environment files, generated data, editor history and dependencies are excluded.

## Publishing
GitHub Pages deploys the main branch, repository root. Preview with `python3 -m http.server 4193`. The catalog generator expects a `dist` directory containing the site files. Source credit is retained in the project archive. These are independent tutorial-derived presentations, not company commissions or full streaming services.
