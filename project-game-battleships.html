Battleships

Overview

Place a fleet on a grid and search for the opposing ships through turn-based attacks. Each result provides information about which locations have been hit or remain unknown.

The game combines hidden information with spatial reasoning. A successful hit suggests where the rest of a ship may lie, while a miss rules out one part of the board. The overview introduces the fleet layout and attack grid, with the playable computer-opponent version available through Demo.

What it includes

  • Fleet placement
  • Grid-based attacks
  • Hidden opponent positions
