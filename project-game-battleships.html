Experience

Place a fleet on a grid and search for the opposing ships through turn-based attacks. Each result provides information about which locations have been hit or remain unknown.

02

Description

The opponent’s layout is hidden, so an attack is both an attempt to damage a ship and a request for new information. A hit suggests a line to investigate; a miss removes one possibility from the search.

The placement phase and the attack phase require different decisions. One arranges a difficult target, while the other interprets incomplete information to work toward clearing the opposing fleet.
